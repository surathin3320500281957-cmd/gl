# Dashboard เงินรับฝาก / เงินจอง / เงินล่วงหน้า

Dashboard สรุปรายการเงินมัดจำ / เงินจอง / เงินล่วงหน้า สำหรับผู้บริหาร เป็นไฟล์ HTML เดี่ยว (single-file) ไม่ต้องมี server หรือฐานข้อมูล ข้อมูลถูกฝังอยู่ในไฟล์ตอนสร้าง

**Live:** โฮสต์อยู่บน GitHub Pages (`surathin3320500281957-cmd.github.io`)

---

## ภาพรวมเทคนิค

- **ไม่มี backend/database** — ข้อมูลทั้งหมด (~9,200 รายการ) ถูกเข้ารหัสแบบ dictionary-compressed แล้วฝังใน `<script type="application/json">` ภายในไฟล์ HTML เดียว
- **ไม่มี build tool** ที่ฝั่งผู้ใช้ — เปิดไฟล์ `.html` ในเบราว์เซอร์ได้ทันที
- **ต้องต่ออินเทอร์เน็ต** ตอนเปิดใช้งาน เพราะโหลดฟอนต์ Sarabun จาก Google Fonts และไลบรารี SheetJS (สำหรับ Export Excel) จาก cdnjs
- Stack: Vanilla HTML/CSS/JS ล้วน ไม่มี React/framework

## โครงสร้างไฟล์ Excel ต้นฉบับที่ต้องใช้

ไฟล์ที่ส่งมาอัปเดตข้อมูลทุกเดือน **ต้องมี sheet ชื่อ `ONLYDATA` เท่านั้น** (sheet อื่นถูกลบออกไปแล้วตั้งแต่รอบแรก) โครงสร้างคอลัมน์ (อ้างอิงตำแหน่ง ไม่ใช่ชื่อหัวตาราง):

| ตำแหน่ง | ชื่อหัวตาราง (ในไฟล์) | ใช้ในงานหรือไม่ |
|---|---|---|
| D | ชื่อGL | ✅ ตัวขับเคลื่อนหลัก |
| E | กอง | ✅ ตัวกรอง |
| F | สคจ./สคล. | ✅ ตัวกรอง |
| H | ชื่อโครงการ | ✅ ตัวกรอง (ค้นหาได้) |
| N | กลุ่มการดำเนินงาน | ✅ ranking chart |
| O | รายละเอียดดำเนินงาน | ✅ ตารางรายละเอียด |
| P | ประเภทรายการ | ✅ รายเดิม / รายใหม่ / Clear |
| R | (ในไฟล์ชื่อ "ส่วนต่าง") | ✅ ตัวเลขจำนวนเงินส่วนต่าง |
| S | (ในไฟล์ชื่อ "จำนวนเงินส่วนต่าง") | ✅ ข้อความ เพิ่มขึ้น/ลดลง/เท่าเดิม |
| T | จำนวนเงินสุทธิ | ✅ ยอดหลักของทุกการ์ด/กราฟ |

> ⚠️ **จุดสำคัญที่ต้องรู้:** หัวตารางคอลัมน์ **R และ S ในไฟล์ต้นฉบับสลับความหมายกัน** (R ชื่อ "ส่วนต่าง" แต่เก็บตัวเลข, S ชื่อ "จำนวนเงินส่วนต่าง" แต่เก็บข้อความ) เป็นความคลาดเคลื่อนจากไฟล์ต้นทางเอง — dashboard ดึงข้อมูลโดยอ้างอิง **ตำแหน่งคอลัมน์** ไม่ใช่ชื่อหัวตาราง จึงไม่ได้รับผลกระทบ แต่ถ้าโครงสร้างไฟล์เปลี่ยนตำแหน่งคอลัมน์ไปจากเดิม ต้องแจ้ง Claude ให้ปรับ mapping ใหม่

## กติกาสำคัญที่ต้องคงไว้เสมอ (Business Rules)

เวลาขอแก้ไข/เพิ่มฟีเจอร์ กติกาต่อไปนี้ต้องไม่เปลี่ยน เว้นแต่ตั้งใจแก้โดยเฉพาะ:

1. **"ส่วนต่าง" มีความหมายเฉพาะกลุ่ม "รายเดิม" เท่านั้น**
   แถวที่เป็น รายใหม่ หรือ Clear มีตัวเลขค้างอยู่ในคอลัมน์ R จากไฟล์ต้นฉบับ (สันนิษฐานว่าเป็นค่าตกค้างจากตอนที่รายการยังไม่ถูกจัดกลุ่ม) — dashboard **บังคับซ่อนเป็น "–" และคิดเป็น 0 เสมอ** ในทุกจุดที่เกี่ยวข้อง: ตารางสรุป, ตารางรายละเอียด, การเรียงลำดับ (sort), และไฟล์ที่ Export Excel

2. **การ์ด "ยอดรวมสุทธิ"** = ผลรวมของ รายเดิม + รายใหม่ เท่านั้น (ไม่รวม Clear)

3. **หลัก cross-filter แบบ "ไม่กรองตัวเอง" (exclude-self)** — การ์ดและกราฟทุกตัวคำนวณค่าจากข้อมูลที่ไม่รวมตัวกรองของตัวเอง เพื่อให้ยังเทียบกับตัวเลือกอื่นได้เสมอแม้กำลังกรองอยู่ (เช่น กด "รายเดิม" แล้ว การ์ด "รายใหม่"/"Clear" ยังโชว์ยอดเต็มของตัวเองตามปกติ ไม่ใช่ 0)

4. **breakdown เพิ่มขึ้น/ลดลง/เท่าเดิม** (อยู่ในการ์ดรายเดิม) ผูกกับ `card=รายเดิม` เสมอ — ถ้าสลับไปการ์ดอื่น ตัวกรองนี้จะถูกล้างอัตโนมัติ กันตัวกรองค้างแบบงงๆ

## ฟีเจอร์ทั้งหมด

- **การ์ดสรุป 4 ใบ** (กดกรองได้): ยอดรวมสุทธิ / รายเดิม (มี breakdown ย่อยเพิ่มขึ้น-ลดลง-เท่าเดิม กดกรองได้) / รายใหม่ / Clear
- **กราฟ ranking 3 มิติ** (กดแท่งกรองได้, คลิกซ้ำยกเลิก): ชื่อ GL, สคจ./สคล., กลุ่มการดำเนินงาน
- **ตัวกรองบนสุด:** กอง, สคจ./สคล. (dropdown), โครงการ (searchable combobox — พิมพ์ค้นหาได้ + โชว์โครงการยอดนิยมเมื่อยังไม่พิมพ์)
- **Chip แสดงตัวกรองที่ active** ทั้งหมด พร้อมปุ่มลบทีละอันและปุ่มล้างทั้งหมด
- **ตารางสรุปตามประเภทรายการ**
- **ตารางรายละเอียด:** ค้นหา, เรียงลำดับทุกคอลัมน์, แบ่งหน้า (50 แถว/หน้า)
- **Export Excel** (เฉพาะข้อมูลที่กรอง/ค้นหาอยู่ ณ ขณะนั้น) และ **Export PDF** (ใช้ print ของเบราว์เซอร์ ซ่อนส่วนควบคุมอัตโนมัติ)
- Design: โทนสีสว่าง (กุหลาบ/เขียวเทอร์ควอยซ์/ส้มทอง/ม่วง), ฟอนต์ใหญ่อ่านง่าย เหมาะกับผู้บริหารที่ต้องการความชัดเจนรวดเร็ว

## วิธีอัปเดตข้อมูลเดือนใหม่

1. เปิดแชทกับ Claude (แชทเดิมหรือแชทใหม่ก็ได้)
2. แนบไฟล์ Excel ที่มี sheet `ONLYDATA` โครงสร้างคอลัมน์เดิม
3. พิมพ์บอกว่าต้องการอัปเดตข้อมูล dashboard
4. Claude จะตรวจสอบโครงสร้างคอลัมน์ให้ตรงกับที่ใช้อยู่ก่อนเสมอ แล้วสร้างไฟล์ HTML ใหม่ (ใช้โค้ด/ดีไซน์/ฟีเจอร์เดิมทั้งหมด เปลี่ยนแค่ข้อมูล)
5. นำไฟล์ใหม่ไปแทนที่ไฟล์เดิมบน GitHub Pages

> ไฟล์นี้เป็น **static file** — ไม่ได้ต่อฐานข้อมูลสด ต้องขอไฟล์ใหม่จาก Claude ทุกครั้งที่มีข้อมูลเดือนใหม่ (ไม่สามารถอัปเดตข้อมูลจากในเบราว์เซอร์ได้เอง)

### เริ่มแชทใหม่กับ Claude
พิมพ์ทำนองนี้: *"ต่อจากที่คุยเรื่อง dashboard เงินมัดจำ เงินจอง เงินล่วงหน้า อยากจะอัปเดต/แก้ไข..."* — Claude สามารถค้นประวัติแชทเก่าเพื่อดึงบริบทได้เอง หรือจะแนบไฟล์ README.md นี้พร้อมไฟล์ HTML เวอร์ชันปัจจุบันให้ Claude อ่านก่อนเริ่มงานก็ได้เช่นกัน

## ข้อจำกัดที่ควรรู้

- ต้องเปิดผ่านอินเทอร์เน็ต (โหลดฟอนต์ + ไลบรารี Export Excel จาก CDN)
- ไม่รองรับการแก้ไขข้อมูลย้อนหลังจากในตัว dashboard เอง — ต้องแก้ที่ไฟล์ Excel ต้นทางแล้วขอไฟล์ใหม่
- จำนวนข้อมูลรองรับได้สบายในระดับหมื่นแถว หากข้อมูลเพิ่มมากกว่านี้หลายเท่า ควรแจ้ง Claude เพื่อพิจารณาปรับโครงสร้างการโหลดข้อมูล
